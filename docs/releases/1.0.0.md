# Release 1.0.0 — Baseline (2026-07-11)

First production delivery to the client. This document is the historical baseline:
read it before starting Release 2 work.

## Overview

Multi-channel messaging gateway: one public endpoint (`POST /sendtext`) dispatching
SMS (REVE), WhatsApp text/media (WaTrend), and Voice campaigns (NetZero), with
automatic channel fallback, a full Angular admin dashboard, automated backups, and a
non-technical client deploy package.

## Delivered features

- **Gateway**: `/sendtext` with channel tags, REVE-compatible responses, required
  `apikey`/`secretkey`/`callerID` validated against the active SMS channel config,
  constant-time comparison, secret masking in audit logs.
- **Dispatch**: per-channel strategies; SMS/Voice batched per tag, WhatsApp per
  recipient; fallback policies (global or per-trigger-channel, activatable).
- **Admin dashboard** (Angular 18 + Material): dashboard with 15-min auto-refresh,
  message/delivery/API logs with filters and detail dialogs, manual send (SMS/WA
  text/WA media/Voice), channel config management with activation, fallback rules,
  user management, DB backup download presets, Gateway Simulator page (SuperAdmin)
  doubling as third-party integration documentation.
- **Roles**: SuperAdmin vs Admin enforced in sidebar, routes, and API
  (`authorization.json`: AdminUser, ChannelConfig, FallbackPolicy = SuperAdmin).
- **Auth**: JWT access 15 min / refresh 7 days (client-mandated), tokens persisted in
  localStorage (client-accepted XSS tradeoff), single-flight refresh in interceptor.
- **Backups**: nightly xlsx (30-day window) + pg_dump (30-day retention) at 00:00
  GMT+6 via the compose `backup` service; on-demand xlsx export in the UI.
- **Delivery**: public Docker Hub images `learnersight/netzero-gateway-{api,web,backup}`;
  `deploy/` client package.

## Architectural state

See [../architecture.md](../architecture.md). Clean Architecture held throughout;
no shortcuts crossing Application→Infrastructure. UI is thin config over shared
primitives (data-table, filter-bar, ListState, BaseCrudService).

## Known limitations & technical debt (priority order)

1. **No automated tests, no CI** — everything verified manually ([testing.md](../testing.md)).
2. **No HTTPS/TLS in the stack** — requires an external reverse proxy in production.
3. **No rate limiting** on `/sendtext` — a flood creates unbounded jobs.
4. **Production secrets baked into the public api image** (appsettings in
   `learnersight/netzero-gateway-api`) — should move to env vars/compose secrets.
5. **Single shared apikey/secretkey** for all integrators (it doubles as the SMS
   provider credential) — no per-client keys, quotas, or revocation.
6. **Seq has no retention cap** — its volume grows unbounded.
7. Dispatch/API log CSV export only covers the current page; API logs have no export.
8. No per-recipient delivery status view (Channel Breakdown counts provider calls).
9. `ng lint` not configured; no eslint in the UI.
10. Frontend "mock mode" drifts from the real API unless maintained.

## Postponed work (from pre-1.0 suggestions)

Dedicated per-channel log pages; deep-linkable message detail route
(`/logs/messages/:id`); dispatch-job detail view with raw provider request/response;
dashboard provider-health indicators; virtual scrolling for large tables.

## Assumptions

- One deployment per client, single-tenant, low-to-moderate volume (thousands/day).
- Providers: REVE SMS, WaTrend WhatsApp, NetZero voice campaigns — base URLs in
  `authorization.json` `Providers` section.
- Client runs the stack via the `deploy/` package on their own machine/VPS.
- Bangladesh-first: GMT+6 backups, `88`-prefixed numbers in examples (digits only, no `+`).

## Lessons learned (cost us time once — don't repeat)

- `docker compose build` tags `netzero-gateway-*`; pushing `learnersight/*` without
  retagging re-pushes the stale image (an all-"Layer already exists" push is the tell).
- Backend errors are ProblemDetails: clients must read `detail`/`title`, not `message`.
- `<ng-template appColumnDef>` renders nothing unless `ColumnDefDirective` is in the
  component's `imports` — silent failure, blank cells.
- EF snake_case: any external SQL (Python backup) must use snake_case column names.
- `python:3.12-slim` is Debian trixie — PGDG bookworm repo conflicts; Debian's own
  postgresql-client 17 can dump PostgreSQL 16.
- Docker Hub free plan: 1 private repo, no private collaborators; privacy is toggled
  only via `POST .../privacy/` (PATCH silently no-ops).
- Material dialogs focus the first tabbable element — with async content that's the
  bottom Close button; use `autoFocus: 'dialog'`.
- Client-rejected ideas (do not re-propose): longer token lifetimes; auto-starting
  Docker Desktop; Swagger in production.
